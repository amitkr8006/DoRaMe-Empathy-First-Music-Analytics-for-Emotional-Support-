# DoReMi-Empathy-First-Music-Analytics-for-Emotional-Support
DoReMi is a concept for empathy-first music intelligence: it fuses listening behaviour (genre+mood, time-of-day BPM, repetition loops, listening time) with psychological signals to infer emotional state, then offers gentle supports—transition tracks, breathing prompts, journaling and mood check-ins—turning playlists into proactive care.
